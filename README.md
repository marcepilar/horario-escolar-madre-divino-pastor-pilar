# Instituto Madre del Divino Pastor · Pilar — Horario Escolar V1.0.0 (DEMO DE PRUEBA)

Desarrollo independiente de MARK-TECH SOFTWARE. **NO OFICIAL**, sin vinculación institucional. Los 12 cursos (1.º–6.º A/B), las materias, los turnos y los horarios son inventados para demostrar la PWA; ciclo 2027.

Identidad institucional verificada en https://www.divinopastor.com.ar/ .
Banner e íconos gráficos IMDP: **recreación visual referencial**, no escudo ni marca oficial del colegio.

Incluye seis idiomas (es/en/pt/fr/de/it), temas Dark Blue/Claro/Dark, selector de curso, tarjetas y recreos, indicadores Hoy/En curso/Recreo ahora, WhatsApp, QR y guía de instalación.

## GitHub Pages
1. Crear repositorio público `horario-escolar-madre-divino-pastor-pilar` en el usuario `marcepilar`.
2. Descomprimir el ZIP y subir **su contenido**, no el ZIP, a la raíz de la rama `main`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. URL prevista una vez que Pages publique: https://marcepilar.github.io/horario-escolar-madre-divino-pastor-pilar/
5. Probar instalación PWA en Android/iOS y actualización service worker antes de aprobar estable.

**Nota sobre vista interactiva:** en algunos celulares la app de archivos abre HTML como texto. En ese caso utilizar GitHub Pages por HTTPS o abrir el HTML con un navegador que admita archivos locales.

**Estado:** versión DE PRUEBA y SIN PUBLICAR. El QR incorporado al ZIP antes del despliegue es ilustrativo; cuando esté en GitHub Pages, la ventana Compartir genera un QR con la dirección publicada si hay conexión.
